How the estimate is built

Only critical alerts page. The number of critical alerts a week is services times alerts times the critical share, rounded. The grouping window divides that by how many alerts it merges into one page and rounds up, so with no grouping every critical alert is its own page.

About two thirds of pages arrive outside working hours, because services fail more often during deploys and batch jobs, which run overnight.
