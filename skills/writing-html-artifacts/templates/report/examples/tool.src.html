How the estimate is built

Demand is engineers times builds times minutes, spread over an 8 hour working day. That gives the average number of runners busy at once. The result multiplies it by the busiest-hour factor, then adds the spare capacity and rounds up.

The estimate assumes every build uses one runner for its whole duration. Builds that split across several runners need the total runner minutes as the build length.
