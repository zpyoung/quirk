# 3D shots with headless Blender

Write a scene script, render it with `blender_render.py`, and composite the resulting clip in HyperFrames. The runner applies the guards that the trials showed Blender needs; do not call Blender yourself for the final render.

`SKILL_DIR` is the directory holding SKILL.md; `P` is the video project folder.

## When 3D earns its place

Propose a 3D shot when depth carries meaning that flat motion cannot: a wordmark or product object revealed on a turntable, layers or stacks seen in space, an end card that needs weight. Leave 3D out for UI screens, dense text and anything under a few seconds. Expect a clean product-shot look, not polished motion design: the trial's turntable was judged "good enough for an end card".

Put the shot in the storyboard marked as 3D, with Blender's status from `doctor.py check --need 3d`. Render nothing until the user has approved the storyboard.

## Workflow

1. Create an empty `.blend` under the project, outside any version folder.
2. Write the scene script that builds the scene in it.
3. Run `blender_render.py`; read its JSON and `guard.json`.
4. Copy `clip.mp4` (or `clip.mov`) into `scenes/assets/` and composite it.

```bash
BLENDER="${QUIRK_BLENDER:-$(command -v blender || echo /Applications/Blender.app/Contents/MacOS/Blender)}"
mkdir -p "$P/assets/3d"
"$BLENDER" -b --factory-startup --python-exit-code 1 \
  --python-expr "import bpy; bpy.ops.wm.save_as_mainfile(filepath='$P/assets/3d/shot.blend')"
```

## Writing the scene script

The script only builds the scene. `blender_render.py` runs it, then runs `bl_guard.py` automatically as a second `--python` script; you never import the guard. The guard inspects the scene, sets the output path itself, renders the frame range and writes `guard.json`.

The script must:
- Delete the startup objects first (`for o in list(bpy.data.objects): bpy.data.objects.remove(o)`), then build everything: geometry, materials, lights, a camera set as `scene.camera`, resolution and `scene.render.fps`.
- Keyframe the motion across the whole `--frames` range. The guard steps through every frame to test text facing.
- Accept extra arguments. Blender passes everything after `--` (`--out`, `--frames`, `--alpha`) to every script, so parse with `parse_known_args`, never `parse_args`:

  ```python
  import argparse, sys
  argv = sys.argv[sys.argv.index("--") + 1:] if "--" in sys.argv else []
  parser = argparse.ArgumentParser()
  parser.add_argument("--brand-hex", default="#1e7a52")
  args, _ = parser.parse_known_args(argv)
  ```

It must not set `render.filepath`, call `bpy.ops.render.render`, or pass `-o`/`-a`; the guard owns output because Blender runs arguments in order and a misplaced `-o` or `-a` silently redirects it.

Blender 5.x notes: the EEVEE engine id differs by version (see [Engine](#engine)); keyframe curves live under `action.layers`, strips and channelbags, so avoid reaching into `action.fcurves`. For linear motion set `bpy.context.preferences.edit.keyframe_new_interpolation_type = "LINEAR"` before inserting keyframes.

## Running the render

```bash
python3 "$SKILL_DIR/scripts/blender_render.py" --blend "$P/assets/3d/shot.blend" \
  --script "$P/assets/3d/shot.py" --out "$P/assets/3d/shot-out" --frames 1-120 --fps 30
```

| Flag | Meaning |
|---|---|
| `--blend FILE` | The scene file. Required and must exist; a missing file would otherwise render Blender's default cube without complaint. |
| `--script PY` | Your scene script. |
| `--out DIR` | Frames, `guard.json` and the clip land here. Must be inside the studio or the cache, and never inside a version folder (`v1/`, `v2/`). Use a folder under the project so `verify.py` finds `guard.json`. |
| `--frames A-B` | Inclusive frame range, for example `1-120`. |
| `--chunk N` | Render N frames per Blender process and merge the guard results. Use it for long ranges. |
| `--alpha` | Render RGBA with a transparent film; keeps the PNG sequence and writes `clip.mov`. |
| `--fps N` | Encode rate. Default `$QUIRK_VIDEO_FPS`, else 30. Match it to the HyperFrames fps and `scene.render.fps`. |

The runner builds this command, and the order is the point:

```
blender -b FILE --python-exit-code 1 --python PY --python bl_guard.py -- --out DIR --frames A-B [--alpha]
```

- The `.blend` comes before `--python`, or the script runs against the default scene.
- `--python-exit-code 1` is already applied. Without it a Python error in your script still exits 0 and the render carries on with a broken scene.
- Blender is found at `$QUIRK_BLENDER`, else `blender` on PATH, else `/Applications/Blender.app/Contents/MacOS/Blender`. None found exits 3 with the install pointer. A missing ffmpeg exits 3 too.
- Without `--alpha` the PNGs encode to `clip.mp4` (H.264, yuv420p, CRF 14). With `--alpha` they encode to `clip.mov` (ProRes 4444) and the PNGs stay.

The JSON on success is `{frames, out, clip, guard, warnings}`. Read `warnings`. Exit 1 carries an `error`: Blender exited non-zero (the stderr tail is included), `guard.json` or a frame is missing, the scene is the default scene, or text is mirrored.

Budget time: a 1080p EEVEE scene at 64 samples took about 1.75 s per frame in the trial (120 frames in 3.5 minutes on a shared machine). Run anything over a couple of minutes in the background and wait for the JSON.

## Colour

Set the view transform to Standard and use emission shaders for exact brand colours. Blender's default view transform, AgX, tone-maps: in the trial a flat `#3B82F6` came out as `(87,139,202)` under AgX and exactly `(59,130,246)` under Standard. The guard warns when the transform is not Standard.

Shader inputs are scene-linear, so convert each brand hex from sRGB first:

```python
def to_linear(c): return c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4
def brand(hexstr):
    r, g, b = (int(hexstr[i:i + 2], 16) / 255 for i in (1, 3, 5))
    return (to_linear(r), to_linear(g), to_linear(b), 1.0)

scene.view_settings.view_transform = "Standard"
scene.view_settings.look = "None"
mat = bpy.data.materials.new("accent"); mat.use_nodes = True
nodes = mat.node_tree.nodes; nodes.clear()
emit = nodes.new("ShaderNodeEmission")
emit.inputs["Color"].default_value = brand("#1e7a52")
emit.inputs["Strength"].default_value = 1.0
out = nodes.new("ShaderNodeOutputMaterial")
mat.node_tree.links.new(emit.outputs["Emission"], out.inputs["Surface"])
```

Surfaces lit by lamps (Principled materials) drift from the swatch; in the trial the platter's green went darker and greyer. Use emission for anything that must match the brand exactly, and lit materials for shape.

`bl_rna` lists only `NONE` for `view_transform` because it is a dynamic enum, so do not use it to validate the name; assign `"Standard"` directly.

## Fonts

Load TTF or OTF files only. Blender cannot load woff2: a file named `.woff2` failed with `unsupported font format`, and HyperFrames' cached Outfit files are woff2 subsets. Get the static TTF or OTF from the brand's font files in `brand.json`, or download it into `$P/assets/fonts/`.

```python
font = bpy.data.fonts.load("/abs/path/Outfit-SemiBold.ttf")
curve = bpy.data.curves.new("title", "FONT"); curve.body = "quirk"; curve.font = font
```

Use absolute paths. One font datablock per style: set `font_bold` and the others explicitly if the text mixes weights.

## Engine

EEVEE is the default and renders headless on macOS. The engine id changed between releases, so set it defensively:

```python
for name in ("BLENDER_EEVEE", "BLENDER_EEVEE_NEXT"):
    try:
        scene.render.engine = name
        break
    except TypeError:
        continue
```

`BLENDER_EEVEE` is the id in 5.x; 4.2 to 4.5 used `BLENDER_EEVEE_NEXT`. A script written for one breaks on the other. Avoid Blender 4.2.0, whose command-line EEVEE leaked memory on a Mac until it froze (fixed in 4.2.4).

Cycles needs Metal chosen explicitly in background mode, and the first run after an install or upgrade spends minutes compiling kernels (1:35 in the trial):

```python
scene.render.engine = "CYCLES"
prefs = bpy.context.preferences.addons["cycles"].preferences
prefs.compute_device_type = "METAL"
prefs.get_devices()
for d in prefs.devices:
    d.use = d.type != "CPU"
scene.cycles.device = "GPU"
```

Pick Cycles only when EEVEE cannot do the look (heavy reflections or glass).

## Mirrored and edge-on text

Text must face the camera on every rendered frame. The guard takes each render-visible text object's world +Z direction and its unit vector to the camera. A negative dot product means the camera sees the back, so the text is mirrored; the render is refused and the run exits 1 with the `mirrored_frames`. A dot within 0.2 of zero means nearly edge-on; that is a warning in `edge_on_frames`, not a failure.

Blender text lies flat and faces +Z, so a camera looking along +Y needs the object rotated 90 degrees about X to read correctly. After that:
- Ease rotations so the text faces the camera at rest and at the start and end frames. A full 360-degree linear turn passes through the back face every loop; in the trial the opening frame was the mirrored back and only the cut timing hid it.
- Prefer a sway out and back over a full turn, and keep the angle under about 75 degrees so the dot product stays above the 0.2 edge-on limit.
- If text must pass edge-on, time the cuts and fades so those frames are not on screen, and read `edge_on_frames` to find them.
- Keep titles that must be read in HyperFrames, not in Blender. Convert nothing to a mesh to dodge the guard: the viewer would still see mirrored text.

## Compositing the clip

Copy the clip into the HyperFrames project and play it as a `<video>`; keep readable copy as HyperFrames text over it so `check` can measure its contrast and position.

```html
<video id="turn" class="clip" src="assets/clip.mp4" muted playsinline
  data-start="0" data-duration="6" data-media-start="0"></video>
```
```js
tl.fromTo("#turn", { opacity: 0.3 }, { opacity: 1, duration: 0.6, ease: "power2.out" }, 0);
```

Start the fade at 0.3 opacity, not 0: `check` warns `first_frame_empty` when frame 0 paints only the background. `data-media-start` starts partway into the clip. Never call `play()` on the video, and to move or resize it animate a wrapper `<div>` and leave the timing on one of the two, not both.

For transparency, render with `--alpha` and use the `.mov` (ProRes 4444) or the PNG sequence. HyperFrames transcodes ProRes inputs to browser proxies; this skill has not confirmed that alpha survives. Render a draft over a coloured background and look at a decoded frame from the MP4 before relying on it. If alpha does not survive, drop `--alpha` and render the 3D clip on the brand ground colour.

Loops: key a turntable from frame 1 to frame N+1 at 360 degrees and render only frames 1 to N, so the last frame does not repeat the first.

## When Blender is missing

Never render a 3D shot the user has not seen in the storyboard, and never install Blender yourself. `doctor.py check --need 3d` returns the install command; `blender_render.py` exits 3 with it when no binary is found. Offer three choices: strike the shot, install Blender (blender.org, or set `QUIRK_BLENDER` to the binary), or approve a 2D fallback built in HyperFrames that carries the same idea. Build the fallback only after the user picks it, and update the storyboard to say so.
