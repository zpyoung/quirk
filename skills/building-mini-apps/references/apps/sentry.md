## Patterns fed

- list-peek: dense multi-line rows with a severity bar, hover that tints the whole row, and an empty state that names the cause; Sentry opens a full page instead of a peek, so the clone uses list-peek's `onOpen` path only.
- expand-in-place: collapsible event sections on the issue page; not used as a pattern in the clone, the sections are plain collapsibles.
- action-palette: a centred ⌘K palette with page-scoped actions above navigation; proposed revision for a multi-item target.
- doc-collections: not fed.
- workspace-panes: the icon rail plus section nav layout; the clone uses the base shell instead.
- staged-table-edit: not fed; Sentry applies actions immediately.
- mini-full: not fed.
- view-switcher: saved views as tabs and starred nav items, with an unsaved-changes dot and Save, Save as new view and Reset; proposed revision.
- assisted-notes: not fed; AI summaries are left out.
- inspector: the issue page's right rail (first and last seen with releases, ownership, activity) and the span side panel.
- Proposed: bulk-select, query-tokens, conditional-status, stack-trace, event-timeline, facet-bars, span-waterfall, replay-player, aggregate-builder (see the blueprint).
