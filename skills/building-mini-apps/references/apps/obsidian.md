## Unseen

- Dragging a tab: the drop-zone highlight, the split preview, and what happens to the dragged tab on release. S5 describes it in text only.
- The right-click tab menu itself (Split right, Split down, Pin, Close others) and the tab-list chevron dropdown.
- What a tab group does when its last tab closes, and which tab gets focus after ⌘W (S2-0050 shows only the moment the shortcut was pressed).
- Resizing a pane by its edge and the minimum widths at which a pane or sidebar collapses.
- Saved-layout switching, tab stacks, and linked-view panes in use; only their documentation was read.
- Editing a cell directly in a base table, selecting rows, resizing or reordering columns, and keyboard navigation inside a base.
- Base table, cards and list views with long values, many rows (scrolling or paging behavior), or a failing filter; no error or invalid `.base` state was shown.
- Kanban and Map layouts, grouped views with collapsed groups, and Group or Sort menus open.
- Explorer keyboard navigation, inline rename, and delete, including what the open tab shows after its file is deleted or renamed.
- What the status bar and tab show when a file changes on disk outside the app.

## Patterns fed

- workspace-panes: the clearest source. Ribbon, explorer, tab groups and right sidebar as bands; per-group tab strips; split by modifier-click or drag; tabs as views with no per-file de-duplication; empty new-tab pane with four text links and their shortcuts; shortcut set for new, close, switch and reopen tabs; layout persists between launches.
- doc-collections: explorer as a plain listing of real files with type badges, hover tooltip of created and modified times, drag-to-folder with a "Move into" chip.
- view-switcher: a base with named views and layouts (table, cards, list), a toolbar with Sort, Filter, Properties and New, a results count, filters in "All views" and "This view" scopes that update results immediately.
- inspector: the Properties block above a note and the right-sidebar tab icons (graph, backlinks, outline) that follow the active note.
- action-palette: centered command modal with matched-letter emphasis, first row preselected, and a footer of key hints; also the `[[` inline suggestion popup with path under each name.
- expand-in-place: bases and PDFs embedded inside a note with their own toolbar, so the same data appears in the note and in its own tab.
- list-peek: card and row density in a base, and result count dropping as filters apply.
- assisted-notes: `[[` link suggestions with `#`, `^` and `|` hints; the raw Markdown marker revealed only on the cursor line.
- staged-table-edit: filter rows built from property, operator and value, with a raw-syntax toggle; no cell editing was seen.
- mini-full: a base opens either embedded in a note at column width or as a full tab with the same toolbar.
