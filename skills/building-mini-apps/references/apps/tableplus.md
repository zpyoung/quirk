Captured 2026-10-22 from public pages and videos only; no login, no account.

Frame paths are relative to the skill folder and live in the gitignored media folder. The S3 and S4 screenshots are 1600 px wide, so sizes below are pixels in that image, not points. They show the current macOS dark-theme UI (SQLite 3.53 and PostgreSQL 18.4 sample databases), even where the page is older. The S2 frames show a 2020 light-theme build.

## Unseen

- Commit failure: no source showed what happens when the server rejects a statement (constraint violation, lock timeout) or whether pending changes survive.
- Esc during an in-cell edit, and how an edit is accepted other than Return (Tab, click away); no frame caught the cancel path.
- Undo and redo (⌘Z, ⌘⇧Z) of a single pending change. The docs only say Discard clears the undo history.
- What happens to pending changes when switching tabs, closing a tab or quitting.
- The tint of a pending new row and a pending deleted row inside the data grid; the new row in S3-row-insert is selected, and the red row in S3-discard-changes-button is only inferred to be a delete.
- Safe Mode or Alert Mode confirmation on a grid commit; the dialog seen was for a SQL query.
- Quick Look editor, the date picker under Set Value, multi-row edit through the right sidebar ("Multiple values" placeholder seen only in a dimmed frame).
- Hover states, cursor changes, and any transition or animation timing; all sources are still images or low-detail video.
- Error and offline states (connection lost, failed query shown in the Message tab).

## Patterns fed

- staged-table-edit: the core model. Edits stay local and tinted (amber changed, green new, red removed) until a Discard / Preview / Commit trio acts on all of them. The trio is dim when nothing is pending, a table in the sidebar carries a pending mark, Preview shows the exact SQL, ⌘S commits, Discard reloads and drops undo history.
- inspector: right sidebar renders the selected row as a labelled form with type captions, shows DEFAULT placeholders for a new row, and toggles with Space.
- view-switcher: a Data | Structure | Index segmented control at the bottom of the grid, and Data | Message | Chart on a result.
- workspace-panes: left tree, center grid, right details, bottom console log, all collapsible, with a narrow connection rail and open tabs across the top.
- action-palette: ⌘P fuzzy "open anything", right-aligned shortcuts in context menus, and key hints printed inline on the filter bar.
- list-peek: the searchable connection list and saved-query list with a solid blue selected row.
