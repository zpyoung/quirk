## Observations

Layout and density

- S4 · `references/media/figma/S4-annotated-layout.png` — Five regions: icon rail (A), left panel (B), canvas (C), right panel (D), floating toolbar (E). Measured on the illustration: rail ~4% of window width, left panel ~17%, canvas ~62%, right panel ~17%. The toolbar is ~35% of window width (~57% of the canvas) and sits ~6% of window height up from the bottom edge. → feeds: inspector, workspace-panes
- S3 · `references/media/figma/S3-0012.png` — Same proportions in a real capture: left panel 0-241 px, right panel 1040-1280 px of a 1280-wide frame (~19% each). Layer rows are 32 px apart in this 720-px-tall frame. → feeds: inspector, workspace-panes
- S2 · `references/media/figma/S2-0105.png` — In the larger-window capture, panels are ~9% of frame width and layer rows 16 px apart, so the row pitch to panel width ratio matches S3 (about 1:7.5). Panels keep a roughly fixed width while the canvas absorbs the extra space. → feeds: inspector, workspace-panes
- S7 · `references/media/figma/S7-blog-move-to-ui3.png` — Page text lists Minimize UI shortcuts: Shift+\ minimizes panels (toolbar stays, the design panel appears only while something is selected, then disappears on deselect), Cmd+\ hides all UI, Cmd+R renames while UI is hidden. S6 adds that panels are resizable. A collapse-panel icon sits at the top-right of the left panel (`S3-0012.png`, `S4-left-sidebar.png`). → feeds: workspace-panes, inspector

## Unseen

- Loading or skeleton state inside the right panel for a selection (only the whole-file load in `S3-0050-loading.png` was seen).
- Error states: failed save, offline, conflicting edits, invalid number in an input.
- Panel resize by dragging the edge, and the Minimize UI (Shift+\) result; only described in S6 and S7 text.
- Keyboard flow inside the right panel: Tab order, arrow-key nudging of a field, scrubbing a field label, Esc to leave a field.
- How a popover closes (click-away vs Esc) and what happens to its edits.
- The trigger for inline layer rename (double-click or key); only the result in `S2-0112.png`.
- Property labels turned on (S6 and S7 describe it in text).
- Dev Mode's inspect panel; S4 and S5 describe it, no frame shows it.

## Patterns fed

- inspector → The right panel keeps one skeleton (pinned header and tabs, then Position, Layout, Appearance, type-specific block, Fill, Stroke, Effects, Export) and swaps blocks per selection type; it falls back to page settings with nothing selected, shows "Mixed" for multi-select, collapses empty sections to a + row, and opens detail editors as floating popovers.
- workspace-panes → Left panel (pages plus layers tree) and right panel are fixed-width docks of ~17-19% each with the canvas taking the rest; both collapse, and Minimize UI shows the right panel only while there is a selection.
- action-palette → A search popover above the bottom toolbar with category tabs, a scope menu and a Suggested group; context menus and tool menus show right-aligned shortcuts and change with the selection.
- doc-collections → Pages as a flat list with emoji status markers and an archive divider; the file browser as a card grid with recents, filters and a grid/list toggle.
- view-switcher → The Design | Prototype segmented control, the Comment | Properties set for view-only users, and the Design/Dev switch inside the toolbar.
- expand-in-place → Layer rows with disclosure chevrons, indented children and hover-only lock and eye icons.
- list-peek → Comment cards in the right panel: avatars, thread number, relative time, reply count, unread dot, and a selected state with a resolve check.
